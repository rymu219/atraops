# AtraOps — Transfer to a New System

## What’s on `D:\`

| Path | Contents |
|------|----------|
| **`D:\AtraOps-Export\`** | Full app code + live backend JSON |
| **`D:\AtraOps-Export.zip`** | Same package, zipped for USB/email |

## Two parts

1. **Code** — HTML/CSS/JS in this folder  
2. **Data** — `AtraOps-backend-LATEST.json` (exported from this PC’s browser)

## On the new system

1. Copy `AtraOps-Export` folder (or unzip the zip) anywhere  
2. Open `index.html` or run `OPEN-AtraOps.bat`  
3. **Admin** → login `admin` / `admin123`  
4. **Import Backend JSON** → choose `AtraOps-backend-LATEST.json`  
5. Confirm replace → done  

## Included in JSON export

- Master categories, connection types, locations, descriptions  
- Admin assets / serial records  
- Document modules (files stored in browser)  
- Equipment lists (ELs), delivery tickets (DTs), receiving reports  
- Rack/bin, sequences, theme
